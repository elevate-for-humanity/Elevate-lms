## RECOMMENDED EPA 608 UNIVERSAL COURSE STRUCTURE

### Phase 1: EPA 608 Certification Prep (6 modules)

```
MODULE 1: CORE - Environmental Regulations
├─ Ozone layer depletion (CFC/HCFC damage)
├─ Global Warming Potential (GWP)
├─ Montreal Protocol
├─ Clean Air Act Section 608
└─ Violations and fines ($44,539/day)

MODULE 2: CORE - Refrigerant Fundamentals
├─ Refrigerant classifications (CFC, HCFC, HFC, HFO)
├─ Pressure-temperature relationship
├─ Bubble point / Dew point
├─ Gauge manifold set operation
├─ Refrigerant oils (mineral, POE, PAG)
└─ Pressure-temperature charts

MODULE 3: CORE - Recovery & Safety
├─ Recovery equipment types
├─ Recovery, recycling, reclamation
├─ Cylinder handling and storage
├─ Safety procedures
├─ Shipping regulations
└─ Confined space entry

MODULE 4: TYPE I - Small Appliances
├─ Equipment under 5 lbs
├─ Recovery requirements (90%/80%/0%)
├─ Self-contained vs system-dependent
├─ Recovery techniques
└─ Disposable vs refillable cylinders

MODULE 5: TYPE II - High-Pressure Systems
├─ Residential AC, commercial refrigeration
├─ Recovery to 500 microns
├─ Evacuation procedures
├─ Leak detection methods
├─ Leak repair requirements and timelines
└─ Record keeping

MODULE 6: TYPE III - Low-Pressure Systems
├─ Centrifugal chillers
├─ R-11, R-123 refrigerants
├─ Recovery to 25 mm Hg absolute
├─ Purge units
├─ Vacuum operation (air leaks IN)
└─ Recharging techniques
```

### Phase 2: Exam Prep & Practice (2 modules)

```
MODULE 7: UNIVERSAL EXAM PREPARATION
├─ PT chart practice drills
├─ Recovery requirement drills
├─ Leak rate calculations
├─ 100-question practice exam
└─ Time management strategies

MODULE 8: CERTIFICATION & NEXT STEPS
├─ Where to take the exam
├─ What to expect day of exam
├─ After passing: next certifications
└─ Career pathways (separate from EPA 608)
```
