# Course Builder workspace and published-route audit — 2026-10-28

## Observed production behavior
- The cosmetology course was published with 40 lessons and 40 saved videos.
- Course Builder displayed an empty lesson selector and a database-operation error; reloading reproduced it.
- The original screen mounted an inner three-pane inspector plus an independent side video player. The two selections were not shared.
- Podcast/program-guide review was mounted inside the course editing workspace.
- Studio had voice-enabled orchestration, but Course Builder did not mount that conversation.
- The published learner handoff redirected to the actual LMS lesson route. Browser inspection then timed out, so live playback acceptance was not established at this stage.

## Focused validation
- 15 Node regression tests: scoped edit/publish/deploy planning, no-op avoidance, draft preservation, failed-copy behavior, identity validation, safe text HTML, receipt navigation and bounded checkpoint inventory.
- 17 targeted React/API tests in an isolated dependency harness: two-pane behavior, exact lesson selection, learner iframe, signed preview index, read-only player, scoped canonical signing and existing saved/versioned playback.
- TypeScript/TSX syntax transpilation passed.
- These checks do not substitute for the full repository typecheck, production build, live model execution, microphone hardware, a learner's enrolled session, or a newly published revised course.

## Publication behavior
A draft text edit is saved separately from an existing live course. It does not claim to regenerate narration, video, assessments, or credential evidence. The revised draft must go through the existing build and release checks. Model/cost authorization, role checks, production confirmation and audit recording remain in place.
