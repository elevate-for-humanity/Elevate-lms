# Cosmetology RTI: non-blocking theory-to-salon enhancement

Scope: cosmetology apprenticeship Related Technical Instruction (RTI). Elevate teaches theory; host shops supervise and document on-the-job learning (OJL). Do not present online lesson completion as verified practical competency.

## Add to future authored technical lessons where relevant
- Clear theory learning objective, terminology, scientific/safety explanation, and concise recap.
- A realistic salon decision scenario and a visual knowledge check based on authorized curriculum.
- A short **From Theory to the Salon** section: what was learned; what to observe/practice with a qualified host-shop trainer; which workplace competency the trainer—not the video—verifies.
- Relevant varied imagery, unique scene titles, synchronized PARIS narration, captions and existing brand standards. Short genuine technique footage is optional, not required for every RTI lesson.
- Link to the approved RTI topic and workplace competency where mappings exist; do not invent regulated hours or claim state-board approval.

## Non-blocking rollout
- Do not interrupt running generation, requeue completed lessons, unpublish lessons, or create draft/placeholder publications.
- New enrichment is best-effort and cannot add a new publication approval gate, mandatory asset dependency, or manual signoff.
- Existing mandatory instructional-source, safety, assessment, video integrity and publication checks remain intact. Never mark incomplete lessons published.
- Apply to future lessons only after the current production run is complete; backfill existing published lessons separately, without regeneration unless necessary.
- Preserve current lesson length targets and sequential progress.

## Acceptance criteria for implementation
1. Feature is cosmetology-RTI scoped, opt-in/default-off during active generation.
2. No new blocking states or job retries from optional scenarios, imagery, or host-shop segments.
3. Generated text correctly distinguishes RTI knowledge from supervised OJL competency.
4. Tests cover optional-content failure, existing publication gates, and continued job progress.
5. Verify on staging before enabling for new production lessons.

This document records approved content/rollout requirements; it does not itself change the live worker or deploy.
