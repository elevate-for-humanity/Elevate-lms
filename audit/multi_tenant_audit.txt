SECTION 7: WHAT "MULTI-TENANT READY" REQUIRES
==============================================

To safely onboard independent institutions:

  1. ADD tenant_id to: courses, lessons, modules, assignments, grades,
     job_placements, notifications (7 ALTER TABLE statements)

  2. ENABLE RLS on all 76+ tables that have tenant_id

  3. CREATE tenant-enforcing policies:
     - SELECT: USING (tenant_id = (SELECT tenant_id FROM profiles WHERE id = auth.uid()))
     - INSERT: WITH CHECK (tenant_id = (SELECT tenant_id FROM profiles WHERE id = auth.uid()))
     - UPDATE/DELETE: same pattern

  4. POPULATE user_roles with tenant-scoped role assignments

  5. BACKFILL tenant_id on existing rows (courses, lessons, modules, etc.)
     using a default tenant for current data

  6. UPDATE application queries to include tenant context
     (most server components already use createClient which carries auth)

Estimated effort: 2-3 days for schema + RLS, 1 week for full application testing.
