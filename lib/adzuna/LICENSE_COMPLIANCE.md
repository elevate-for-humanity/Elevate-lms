# External API License Compliance

## CareerOneStop (National Career Information System)

**License Requirements:**
- Data must be publicly available at no cost
- No login requirements for end users
- Must credit CareerOneStop/Minnesota DEED
- Agreement expires: 4/25/2029

**Required Attribution:**
"This site incorporates information from CareerOneStop, a service of the U.S. Department of Labor's Employment and Training Administration."

**Logo:** Display CareerOneStop logo on pages using their data.

## Implementation Notes

All job/career data features should:
1. Display appropriate attribution
2. Be accessible without login (public pages)
