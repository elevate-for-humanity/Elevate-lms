# Complete lesson acceptance

| Approved requirement | Enforcement before next lesson |
|---|---|
| Complete source-grounded instruction, tools, safety and numbered steps | Instructional author/reviewer and instructional QA |
| Whole changing relevant photos and licensed motion where required | Visual assignments, approved picture timeline and encoded presentation QA |
| Separate fresh recaps and nonoverlapping narration | Narration producer, alignment and narration QA |
| Charcoal, white and champagne styling, side instructions and bottom captions | Approved presentation contract and encoded frame/caption inspection |
| Video, assessment, feedback, retry, progress and practical checkoff | Authenticated staged LMS learner runthrough |
| All stage evidence is current and passes | assertCompleteLesson before marking a lesson built |
| Do not skip a failed lesson | Same-index bounded repairs; external/exhausted blocker pauses that course |
| Do not prebuild later lessons | Current-competency-only draft materialization |
| Do not inherit old output/settings | Fresh course, canonical lesson IDs and build; frozen curriculum-only reference sources |
| Owner review before publishing | New builds set publicationPolicy owner-review-required |

Old courses and student records remain intact until replacement acceptance. Stock sources retain their original private paths and license evidence; no old finished lesson or quiz is reused as the new output.
