## Boundaries

Source/profile repair is not course completion or publication. Barber's saved failure requires scene-relevant licensed practical footage. HVAC Type I has signed browser evidence, but its first run failed captions, uninterrupted playback, progress save, resume and completion; those checks remain blocking until a fresh deployed run passes. These are not cleared by policy inheritance or media copies. The replacement HVAC draft now contains 17 consolidated draft lessons; all 96 source topic records are preserved as source-only. Stage-one build adc2ae08-f739-41e1-ac86-b79802e46f19 targets Core and Type I. The three active teaching sources and their questions were corrected against EPA primary guidance before queuing; draft status is not release approval.

Existing locked and active pool profiles are not silently edited during hydration. New builds receive the shared policy at each creation entry. Existing blocked builds require an explicit guarded migration with no live job/pool and subsequent revalidation of affected checkpoints. Existing published lessons and owner pauses are preserved.

Follow-up root cause: enabling the three-role profile did not remove serial authoring inside coordinateLessonAutopilots. A duplicate or provider failure in a later draft could prevent the entire pool from being created. The coordinator now requests deferred instruction materialization: new rows remain empty, unpublished drafts explicitly marked instructionPending and releasePending until real instruction and release checks pass. Existing canonical lessons remain unchanged. The bounded duplicate-narration correction also receives its rejected blueprint and duplicate count so it can repair the actual source instead of blindly retrying from the original prompt.

Separate learner-acceptance root cause: a later browser failure could inherit an older producer repair directive and wrongly send work back to instruction. Delegation now requires the directive's failed step and exact requirements to match the current blocking findings. An unrelated later failure clears only the obsolete routing state, preserving every certified checkpoint. Browser-check failures are recorded by check name rather than mislabeled as absent evidence.

The shared contract no longer requires a teacher/instructor photograph or a generated photograph for conceptual scenes. It prefers registered, inspected, license-linked Envato media when available, then exact saved stills, and otherwise creates a clearly labelled instructional visual synchronized to narration. Practical skills still require inspected motion footage; an instructional graphic can never satisfy that evidence gate. Saved legacy `teaching-photograph-request` checkpoints remain resumable, but all new scene assignments use the visual-neutral `instructional-visual-request` contract.

Validation: full worker regression suite, profile/registered-profile tests, lint, application type checks/builds, followed by CI and deployment verification. Only completed checks may be reported as passing.

The blocked barber and older HVAC complete-lesson profiles were migrated only with no queued/running jobs or active pool, retaining the previous presentation policy in productionInheritanceAudit. Cosmetology's published profile was not edited. Recovery monitoring now defaults on for new continuations while explicit saved disables remain preserved. The parallel-team request now queues a stopped full-course continuation before requesting the pool, and rejects targeted previews and owner-paused builds.
